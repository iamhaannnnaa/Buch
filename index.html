Wie es funktioniert

  1. NFC-Tag enthält nur die URL der Website.
  2. Die Website lädt Einträge aus Firebase Firestore.
  3. Bilder werden in Firebase Storage gespeichert.
  4. Löschen ist im MVP per Passwort 1234 geschützt.

Für die produktive Version sollte das Löschen nicht im Frontend mit einem sichtbaren Passwort, sondern über Firebase Authentication und sichere Regeln oder eine Cloud Function abgesichert werden.
